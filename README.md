# Una página para Valen ♡

Sitio romántico estático hecho con HTML, CSS y JavaScript. No necesita instalar nada ni usar un servidor para probarlo.

## Archivos

- `index.html`: textos, carta, recuerdos y pantallas.
- `style.css`: colores, diseño adaptable a celular y animaciones.
- `script.js`: navegación, tarjetas sorpresa y corazones animados.
- `assets/`: poné aquí tu canción y tus imágenes.

## Probar en tu computadora

1. Descomprimí la carpeta.
2. Abrí `index.html` con Chrome, Firefox, Edge u Opera.
3. Recorré los botones y probá las tarjetas sorpresa.
4. Para comprobar la música, agregá un archivo MP3 propio o que tengas permiso de usar y guardalo como `assets/cancion.mp3`.

## Personalizar

- Editá los textos directamente en `index.html`.
- Para recuerdos reales, cambiá los títulos y descripciones dentro de `<div class="timeline">`.
- Guardá la canción elegida como `assets/cancion.mp3`.
- Si querés añadir fotos, copiá las imágenes a `assets/` y podemos añadirlas a la página en una siguiente edición.
- En `style.css` podés ajustar los colores que aparecen al principio dentro de `:root`.

## Publicarla gratis con GitHub Pages

1. Creá una cuenta en https://github.com si todavía no tenés una.
2. Creá un repositorio nuevo, por ejemplo `para-valen`. Podés dejarlo público para que Pages gratuito funcione sin complicaciones.
3. Subí `index.html`, `style.css`, `script.js` y la carpeta `assets/` a la raíz del repositorio. No subas solamente el ZIP.
4. En el repositorio, entrá en **Settings → Pages**.
5. En **Build and deployment**, elegí **Deploy from a branch**; seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
6. Esperá a que termine la publicación. GitHub Pages te mostrará una dirección similar a `https://TU-USUARIO.github.io/para-valen/`.
7. Abrí el enlace desde el celular antes de mandárselo a Valen.

Los nombres de menú pueden cambiar un poco. Si el enlace tarda en funcionar, esperá un par de minutos y volvé a probar.

## Consejos importantes

- La página funciona sin conexión para casi todo una vez descargada; Google Fonts necesita internet para cargar la tipografía personalizada.
- No subas información privada, capturas de chats ni fotos que ella no quiera compartir. Un repositorio público hace que los archivos del sitio sean accesibles para cualquiera que tenga el enlace.
- Usá una canción o imágenes propias, o contenido que tengas permiso de publicar.
- GitHub Pages publica una web estática; no guarda respuestas en una base de datos ni manda notificaciones. Si ella toca “Sí”, verá la pantalla de confirmación en su dispositivo.
